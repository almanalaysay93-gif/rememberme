# rememberme — Harness² + Context Mode Every-Session + Synergy (combined)

This is both zips in one, renamed to rememberme.

- every-session/ = basic persistent install (Context Mode every session)
- synergy/ = v2 with 5 feedback loops (shared WAL DB, compose-evidence, lesson persistence, token guardrail, think-in-code)

Install:
  unzip rememberme.zip
  cd rememberme
  chmod +x install-all.sh
  ./install-all.sh

After install, restart shell and inside any agent: ctx-doctor, ctx-stats

Bundle name: rememberme
